## Security foundation added
**Sessions**
- Remote sign-out: tokens carry `tokenVersion`, checked on every request. Available as Sign Out of All Devices (soldier), sign out a member's devices (Readiness NCO, for a lost phone), admin revoke, and on password change.
- Role, unit, and position are loaded from the database on every request, so demotions and transfers apply instantly.
- Tokens: HS256 with issuer/audience pinned.

**Sign-in**
- Lockout after 5 wrong passwords (15 minutes).
- One generic error message and constant timing, so responses don't reveal which emails have accounts.
- New passwords need 12+ characters; bcrypt cost raised to 12.
- `create-admin -- <email> --reset-password` for recovery.

**Server**
- Refuses to start with a weak or missing `JWT_SECRET`, or (in production) without https CORS origins and join link.
- Helmet security headers; CORS allowlist; global rate limit (120/min) plus tighter limits on auth routes.
- Memo uploads: 10 MB cap, real-PDF check by bytes, random file names.
- Logs mask unit join codes.
- Audit log covers logins, failures, lockouts, sign-ups, password changes, and sign-outs.

**Database**
- `synchronize` replaced by migrations (`Init` baseline + `SessionSecurity`).
- The existing dev database was marked as baseline, so no data was lost.
- Migrations run automatically at startup.

**App**
- Face ID / Touch ID / passcode lock at start and after 30 seconds in the background.
- App-switcher privacy cover.
- Phones without a passcode can't open the app.
- Keychain `unlocked_this_device` (not in backups); Android encrypted storage.
- Account sheet: Change Password and Sign Out of All Devices. Manage Unit: sign out a member's devices.

## Afternoon: PT test feature (built while Felix was out)

New **PT Test** tile on Home, fully offline:
- **Score calculator.** AFT events (deadlift, hand-release push-up, sprint-drag-carry, plank, 2-mile run):
  - General or Combat standard, with an optional MOS field that picks combat for the 21 combat MOSs.
  - Sex and age; the age group is shown.
  - Per event: live points, plus "60 pts / 100 pts" targets for that profile.
  - Pass/fail with the exact reason (event under 60, or total under 300/350).
  - Alternate aerobic events (walk/bike/swim/row) as Go / No-Go.
- **Event timers.** HRP 2:00 countdown (haptic at 30 s and 10 s, alert at 0); SDC stopwatch with a 4:00 limit warning; plank stopwatch with live points; run stopwatch. From the calculator, "Use time" fills the field.
- **Run lap tracker.** Set laps (default 8), add runners (optional age/sex for points), one race clock, a big tile per runner to tap each lap.
  - Double-tap guard (3 s), undo last lap, DNF (long-press).
  - Results with splits and points; Copy results.
  - Screen stays awake; leaving mid-race asks first.

**Accuracy.** Tables were extracted from the official Army PDF ("Army Fitness Test Score Tables", approved 15 May 2025, effective 1 Jun 2025) by `frontend/guard_app/tool/pt_standards/extract_aft_2025.py`, which validates every row. Scores were spot-checked independently against the PDF text.

**Updating when standards change.** See `frontend/guard_app/tool/pt_standards/README.md`: generate a new JSON from the new PDF and register it; no scoring code changes.

**Verified.** 57 Flutter tests (incl. 19 scoring tests using official values, lap/clock logic, calculator/lap tracker screens); analyzer clean; Android and web builds compile.
